# Architecture Decision Records

Short, immutable records of significant architectural decisions, written in the
[Michael Nygard format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

- Copy [`_TEMPLATE.md`](./_TEMPLATE.md) to `NNNN-short-title.md` (e.g. `0001-use-grpc-between-gateway-and-engine.md`).
- Numbers are sequential and never reused.
- Once accepted, an ADR is not edited; a later ADR supersedes it and both are updated to link each other.
