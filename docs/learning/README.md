# Learning notes

One note per technology or concept we adopt (gRPC, buf, Fastify, Go concurrency patterns, etc.).
Each note records what the thing is, how it works, how *this project* uses it, and what went wrong
along the way — so the knowledge survives beyond whoever first wired it up.

Start a new note by copying [`_TEMPLATE.md`](./_TEMPLATE.md) to `<topic>.md`.
